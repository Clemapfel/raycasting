<Faq question="When will it come out? What features are still missing?">

    Between now (October 2026) and the release of the demo, the main work left is adding additional sound effects for various gameplay elements. When closed playtesting begins, it is also expected that a few weeks of various platform / driver-specific bugfixing and optimization are still required, as is always the case when shipping software for various platforms. This process is estimated to have finished by the end of 2026.

    Between the demo and the full game, the following features are still required:
    + creating more (~20) levels
    + unique textures, decorations, and backgrounds for themed set of levels. This is a purely visual and artistic process, programming-wise the scaffolding for this is already done
    + unique music tracks for each level
    + online-infrastructure for sharing and comparing level completion times

    While a timeline between now and the release of the full game cannot be set at this time, the demo will release within the next few months. Then, depending on the feedback, audience response, and future funding, the road the full game can be given an exact timeline.

<Faq question="Does this game use AI? What does &quot;procedural&quot; mean?">
    No text, images, music, sound effects, code, documentation, or content in the game, on this page, or any social media associated with "chroma void", was generated by or created with the help of any <Link text="LLM" href="https://en.wikipedia.org/wiki/Large_language_model" />, <Link text="T2I" href="https://en.wikipedia.org/wiki/Text-to-image_model" />), or other prompt-based content generation language model, third-party or otherwise.

    "Procedural", here, refers to generating assets algorithmically. The suite of algorithms used does not include <Link text="stable diffusion" href="https://en.wikipedia.org/wiki/Stable_Diffusion" /> (which is a type of T2I), or any kind of architecture that involves prompting or deep-learning on third-party, scraped, bought, or stolen data of any kind. No external machinery such as cloud- or physical server infrastructure was used to generate any assets in the game.

    For an example of a "non-AI" procedural assets, let's assume the game needs a sound effect of a string being plucked. You can either
    a) have AI generate it from a prompt. This method was __not__ used at any point in development for obvious reasons.
    b) record a physical string being plugged in real life, or buy a recording of a physical string being plugged. Assets of this type are in the game, but are not considered procedural.
    c) model the string as a mathematical function in code, virtually excite that model, then measure the functions output and export it as a sound file. The game then plays back that generated sound file, with neither AI nor a microphone involved in any step of the process.

    This same method of procedural generation was also applied to create textures, backgrounds, and animations for the player or other gameplay objects.

    **Level design is notably not procedural**, every object is placed by hand. There is no "random generation", as is common in other genres such as rogue-lites.
</Faq>
